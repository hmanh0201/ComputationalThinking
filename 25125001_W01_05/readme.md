## AI Usage Declaration

In this assignment, Generative AI (Google Gemini) was used as a support tool for the following purposes:

- **Report Formatting & Markdown Generation:** Assisted in structuring the report layout, converting raw information and tables into clean Markdown syntax, and refining English grammar and phrasing. All original data, project ideas, and final content were provided, reviewed, and validated by the student.
- **Git & Commit Log Guidance:** Provided explanations on basic Git repository setup and the parameters of the `git log` command to extract commit history. All repository configurations and Git commands were executed and verified independently on the local machine.
