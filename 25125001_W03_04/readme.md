# AI Assistance Declaration

During the completion of the coursework exercises and practical lab assignments, an AI assistant was utilized as an interactive learning aid and thought partner. The collaboration strictly adhered to academic integrity principles, emphasizing conceptual comprehension and skill acquisition over direct code generation.

### Scope of AI Assistance

1. **Theoretical Concepts & Machine Learning Fundamentals:** Providing structured explanations of core data science and machine learning topics, including decision trees, bias-variance trade-offs (overfitting vs. underfitting), ensemble learning (Random Forest), and evaluation metrics.
2. **Library Syntax & Mechanics:** Deconstructing the underlying logic, data structures, and memory behaviors of key Python libraries (`pandas`, `numpy`, and `scikit-learn`), specifically vectorized operations, indexing methods, and pipeline APIs.
3. **Debugging & Code Diagnostics:** Assisting in identifying syntax pitfalls, operator precedence issues, and debugging runtime errors encountered across notebook workflows.
4. **Data Preprocessing Strategy:** Providing analytical guidance on structured workflows, specifically evaluating strategies for handling missing values (column dropping vs. imputation methods) and encoding categorical variables (Ordinal Encoding vs. One-Hot Encoding with cardinality constraints).

### Statement of Authorship

All final implementations, model evaluations, notebook runs, and competition submissions were independently reviewed, executed, and submitted by the student. The AI assistant served solely as an explanatory guide and debugging mentor to clarify technical concepts and reinforce hands-on learning.
